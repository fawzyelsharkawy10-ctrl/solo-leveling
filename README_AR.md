# نظام اللاعب — Solo Leveling Inspired RPG

نسخة أولى قابلة للتشغيل من تطبيق ويب عربي باتجاه RTL، مصممة للهواتف.

## ما الذي يعمل الآن؟
- بطاقة حالة اللاعب والمستوى والرتبة.
- خمس مهام يومية بمكافآت XP محددة.
- احتساب XP فور الضغط على «إكمال المهمة».
- منع تكرار مكافأة المهمة نفسها في اليوم نفسه.
- حساب المستوى: كل 100 XP تراكمية = مستوى إضافي.
- تحديث الإحصائيات والرتبة وسجل الإنجازات.
- حفظ محلي تلقائي باستخدام `localStorage`.
- واجهة PWA وملف service worker لتخزين ملفات التطبيق مؤقتًا عند استضافته على HTTPS.

## التشغيل الأسهل على الكمبيوتر
1. فك ضغط الملف.
2. افتح مجلد `solo_leveling_app`.
3. شغّل خادمًا محليًا داخل المجلد، مثل:
   - Python: `python -m http.server 8000`
4. افتح `http://localhost:8000` في المتصفح.

فتح `index.html` مباشرة يسمح بتجربة معظم الواجهة والحفظ المحلي، لكن تثبيت PWA والعمل دون اتصال يحتاجان عادةً إلى HTTPS أو localhost.

## تشغيله على Android
الطريقة الأبسط للمبتدئ:
1. ارفع محتويات المجلد إلى استضافة ثابتة تدعم HTTPS، مثل GitHub Pages أو Netlify.
2. افتح رابط التطبيق في Chrome على Android.
3. افتح قائمة Chrome واختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» إذا ظهر الخيار.

## الحفظ: ما الذي يعنيه؟
هذه النسخة تحفظ الاسم والخبرة والمهام في `localStorage` داخل المتصفح الحالي. تبقى البيانات عادةً بعد إغلاق المتصفح وإعادة تشغيل الجهاز، لكنها ليست نسخة احتياطية سحابية. حذف بيانات الموقع/المتصفح أو استخدام متصفح أو جهاز مختلف قد يجعل البيانات غير متاحة.

## ما الذي لا تتضمنه النسخة الأولى؟
- لا يوجد تسجيل دخول أو مزامنة بين الأجهزة.
- لا يوجد تحقق آلي من أن اللاعب أنجز المهمة فعلًا؛ المستخدم يؤكدها بالضغط.
- لا يوجد إشعار خلفي مضمون أو مؤقت يتحقق من النشاط.
- بيانات XP محفوظة محليًا ويمكن لمستخدم خبير تعديلها من المتصفح؛ لا تستخدم هذه النسخة لنقاط أو بيانات حساسة.

## الملفات
- `index.html`: هيكل الواجهة.
- `style.css`: التصميم المتجاوب.
- `app.js`: منطق المهام والخبرة والمستويات والحفظ.
- `manifest.webmanifest`: تعريف تطبيق PWA.
- `sw.js`: التخزين المؤقت لملفات التطبيق.
- `icon.svg`: أيقونة التطبيق.

## الخطوة التالية للحفظ السحابي
للمزامنة الحقيقية، أضف Supabase أو backend آخر مع حسابات مستخدمين وسياسات أمان. يجب احتساب مكافآت XP والتحقق من عدم تكرارها على الخادم، لا في الواجهة وحدها.
